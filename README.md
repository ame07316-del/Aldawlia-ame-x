# AMK — استوديو بيصنع هزة

موقع تعريفي كامل (عربي RTL) لاستوديو **AMK** للبراندنج والتجارب الرقمية.
HTML + CSS + JavaScript خام، بدون أي build step — ارفع الملفات واشتغل.

## 🌐 الدومين الرسمي

# `amk.studio`

**ليه `amk.studio`؟**

| السبب | التفصيل |
| --- | --- |
| قصير ومحفوظ | ٣ حروف + كلمة واحدة، سهل يتقال على التليفون ويتكتب مرة واحدة. |
| امتداد `.studio` | نفس امتداد أستوديوهات التصميم العالمية (Figma, Instrument, Pentagram-adjacent) — بيقول «إحنا بنصنع» مش «إحنا شركة». |
| متطابق مع الاسم | البحث عن AMK يوصل مباشرة، مفيش لبس مع `amk.com` ولا أي براند تاني. |
| قابل للتوسّع | `work.amk.studio` للأعمال، `brief.amk.studio` للبريفات، `play.amk.studio` للتجارب. |
| SEO | كلمة `.studio` بتظهر في نتائج «design studio» وبتدّي إشارة واضحة لجوجل عن نوع البيزنس. |

بدائل محجوزة كاحتياط: `amk.design` · `amk.agency` · `heyamk.com`

## المميزات في الموقع

- **Preloader** بيفتح على علامة AMK ثم يسيب المكان للـ Hero.
- **هيرو سينمائي**: كلمات بتطلع من تحت، أورا نيون، ووترمارك عملاق، وكارت مشروع 3D بميل مع الماوس (tilt).
- **مؤشر مخصص** + شريط تقدم للسكرول + هيدر بيتصغّر ويثبت مع البلور.
- **شريط متحرك (marquee)** للخدمات.
- **فلترة أعمال** بالتصنيف (هوية / رقمي / حملات / تجارة إلكترونية).
- **أكورديون خدمات** + **أكورديون أسئلة شائعة**.
- **باقات أسعار** واضحة مع باقة مميزة.
- **سلايدر شهادات** بسحب باللمس، نقاط، أسهم، وتشغيل تلقائي.
- **فورم بريف** بتحقق كامل + رسائل خطأ عربية + Toast + حفظ محلي للبيانات.
- **وضع نهاري/ليلي** محفوظ في المتصفح.
- **عدادات أرقام**، ظهور تدريجي للعناصر، أزرار مغناطيسية، ساعة القاهرة، ونشرة بريدية.
- **متجاوب** بالكامل (موبايل / تابلت / ديسكتوب) + احترام `prefers-reduced-motion`.
- **خطوط مستضافة داخلياً** (Alexandria · IBM Plex Sans Arabic · Anton · Space Grotesk) بصيغة woff2 مقتطعة = 290KB فقط، بدون أي طلب لـ Google Fonts.
- SEO: وصف، Open Graph، Twitter Card، JSON-LD، canonical، `robots.txt`، `sitemap.xml`.

## التشغيل

```bash
python3 -m http.server 8000 --bind 0.0.0.0
# افتح http://localhost:8000
```

أو ارفع المجلد زي ما هو على Vercel / Netlify / GitHub Pages.

## النشر على Vercel (الدومين `amk.studio`)

```bash
npx vercel --prod
```

ثم من إعدادات المشروع → Domains → أضف `amk.studio` و `www.amk.studio`،
وحدّد DNS عند المسجّل:

| Type | Name | Value |
| --- | --- | --- |
| A | @ | 76.76.21.21 |
| CNAME | www | cname.vercel-dns.com |

## الهيكل

```
index.html
assets/
  css/style.css      ← نظام تصميم كامل بمتغيرات CSS + وضعين
  js/main.js         ← كل التفاعلات بدون مكتبات
  fonts/             ← خطوط woff2 مقتطعة ومستضافة محلياً
  img/               ← صور المشاريع + og-amk.jpg
robots.txt
sitemap.xml
```

## تخصيص سريع

- **الألوان**: أول كتلة في `style.css` (`--accent` ليموني، `--accent-2` ماجنتا، `--bg` أسود حبر).
- **الاسم/الدومين**: ابحث في `index.html` عن `AMK` و `amk.studio`.
- **الأسعار**: قسم `#pricing`.
- **الأعمال**: كروت `.work-card` مع `data-cat` للفلترة.
- **بيانات التواصل**: قسم `#contact` + الفوتر.
