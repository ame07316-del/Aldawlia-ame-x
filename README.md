## 🕳 الثقب الأسود في أول الموقع

أول شاشة هي **محاكاة ثقب أسود بالكامل على الـGPU** (`assets/js/blackhole.js`):

- كل بكسل بيطلق شعاع ضوء ويمشي بيه **بالعكس في فضاء منحني** (Schwarzschild) لحد ما يقع في الأفق، أو يهرب للسماء، أو يقطع قرص الغاز — وأحياناً **يلف حوالين الثقب ويرجع** يقطعه تاني.
- ده معناه إن الهالة اللي فوق القرص، والهالة اللي تحته، والحلقة الرفيعة الملزّقة في الظل — **كلهم نفس القرص** بيتشاف من خلال ضوء متقوّس. محدش رصّهم، ده اللي طلع من المعادلة.
- الوحدات طبيعية: أفق الحدث `r = 1`، كرة الفوتون `1.5`، القرص بيبدأ من `3` (آخر مدار مستقر ISCO)، وظل الثقب عرضه `2.6`.
- فيزياء إضافية: **دوبلر بيمنج** (الجانب اللي جاي ناحيتك ألمع وأزرق)، تمدد زمني، وكثافة غاز بتعمل ظل لنفسها.
- الصورة بتتجمّع **زمنياً** (TAA) بـ 8 عيّنات Halton لكل بكسل عشان حافة الظل تطلع ناعمة مش مبقّعة.
- **جودة تلقائية**: لو الإطار بقى أبطأ من ~24fps، الكود بينزّل الدقة والخطوات مرة واحدة لوحده.
- بيقف عن الرسم لما تخرج من الشاشة أو تروح لتاب تاني، وبيحترم `prefers-reduced-motion` (بيرندر لقطة ساكنة نظيفة).
- لو المتصفح مش بيدعم WebGL، أو الـGPU سوفتوير: فيه **fallback CSS** على شكل حلقة بلازما بدل ما تطلع شاشة سودة.

### تظبيط المشهد

كل الإعدادات في آخر `blackhole.js` داخل `init()`:

| المتغيّر | التأثير |
| --- | --- |
| `distance` | بُعد الكاميرا (24 قريب / 30 بعيد) |
| `elevation` | فوق/تحت مستوى القرص بالدرجات — قريب من 0 يعطي الهالة الكلاسيكية |
| `roll` | ميل القرص في الكادر (الافتراضي −18°) |
| `focus` | مكان الثقب في الشاشة `[x, y]` — افتراضياً **0.26** يعني على الشمال، عشان النص العربي ياخد اليمين |
| `steps` | خطوات الشعاع — 260 كويس، 160 للموبايل |
| `resolution` | مقياس الرندر (0.56 افتراضي) — نزّله قبل ما تنزّل `steps` |
| `midColor` / `hotColor` / `coolColor` | ألوان الغاز — حالياً ماجنتا `#FF3D8B` + كريمي |
| `doppler` | 0 = حلقة متساوية، 1 = الحقيقة الفيزيائية |

## ✍️ الطبقة البصرية (مش «شكل AI»)

اتبنى الموقع على قاعدة تصميم صريحة بدل الذوق العشوائي:

- **Brutalist editorial**: زوايا 0px، حدود hairline، مساطر أفقية، أرقام أقسام `/01…/08`، وخط mono للبيانات.
- **Grid مكشوف**: سكشن الأعمال والأسعار والخطوات كلهم جداول حدودها ظاهرة — مش كروت دروب-شادو.
- **Typography**: Alexandria للعناوين (800)، IBM Plex Sans Arabic للنص، Anton للأرقام اللاتينية العملاقة، Space Grotesk للـmeta. مفيش letter-spacing على العربي.
- **ألوان دلالية**: حبر `#08080A`، ورق `#F0EEE4`، ليموني `#D7FF2E`، ماجنتا `#FF2F86` — 4 قيم بس.
- **مفيش إيموجي كأيقونات**: كل الأيقونات SVG مرسومة inline بنفس سماكة الـstroke.
- **حركة ليها معنى**: 200–250ms للـhover، 600ms للظهور، وكلها transform/opacity فقط.
- **إيقاع الأقسام**: تبادل `--bg` / `--bg-2` بدل ما الصفحة تبقى لون واحد.

## المهارة المستخدمة (UI/UX Pro Max)

تم تثبيت المهارة من npm كما في التوثيق:

```bash
npm install -g ui-ux-pro-max-cli
uipro init --ai claude --global      # ~/.claude/skills/
uipro init --ai cursor --global      # ~/.cursor/skills/
uipro init --ai zcode --global
uipro init --ai universal --global   # ~/.agents/skills/
```

وبعدين اتشغّل محرّك القرار بتاعها على المشروع:

```bash
python3 ~/.claude/skills/ui-ux-pro-max/scripts/search.py \
  "creative design studio branding agency portfolio" \
  --design-system -p "AMK Studio" -f markdown --variance 9 --motion 8 --density 4
```

اللي رجع: **Brutalism** + **Scroll-triggered storytelling** + تباين عالي وخطوط بولد.
اتطبّق منه: الزوايا الصفرية، الحدود الظاهرة، الجريد المكشوف، الأرقام الضخمة، أسود/أبيض + لون واحد صارخ،
والـanti-patterns اللي اتجنّبناها: «Corporate minimalism» و«Hidden portfolio» و«Emoji as icons».
